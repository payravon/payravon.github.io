# Payravon

## Нашр дар GitHub Pages

1. ZIP-ро кушоед. Файлҳои `index.html`, `config.js`, `app.js`, `style.css` ва папкаи `assets`-ро якҷо ба ҷузвдоне гузоред, ки дар **Settings → Pages** барои нашр интихоб шудааст. Агар `main / (root)` интихоб шуда бошад, файлҳо бояд дар решаи репозиторий бошанд.
2. Дар `config.js` санҷед, ки URL ва калиди оммавӣ ба ҳамон лоиҳаи Supabase тааллуқ доранд, ки ҳисобҳои донишҷӯён дар он ҳастанд.
3. Барои базаи нави холӣ `supabase/migrations/001_initial_schema.sql`-ро як бор дар SQL Editor иҷро кунед. Барои базаи мавҷуда, ки аллакай бо ин схема кор мекунад, SQL-ро такрор накунед.
4. Агар тасдиқи email фаъол бошад, суроғаи нашршудаи сайтро дар URL Configuration-и Supabase сабт кунед ва расидани мактуби тасдиқро санҷед.

## Санҷиш пас аз нашр

- Сайтро дар равзанаи Incognito кушоед ва бо ҳисоби мавҷуда ворид шавед.
- Бо ҳисоби санҷишии нав сабти ном кунед. Агар тасдиқи почта фаъол бошад, истиноди мактубро кушоед. Агар хомӯш бошад, дархост фавран ба ҳолати интизорӣ меравад.
- Ҳисобро бо Admin тасдиқ кунед. Равзанаи Incognito-ро пӯшед, аз нав кушоед ва бо ҳамон email ва парол ворид шавед. Кабинети донишҷӯ бояд кушода шавад.


## Навсозии Payravon Plus (09.11.2026)

**Муҳим: аввал нусхаи эҳтиётӣ аз база созед.** Барои базаи мавҷуда файли
`supabase/migrations/002_points_and_admin.sql`-ро дар **Supabase → SQL Editor → New query**
як бор иҷро кунед. Файли `001_initial_schema.sql`-ро такроран иҷро **накунед**.
Баъд файлҳои сайтро дар GitHub Pages иваз кунед (махсусан `app.js`, `index.html`,
`style.css`). `config.js`-и худро бетағйир нигоҳ доред.

- Ҳисобот ҳозир ҳамаи QR-сканҳои сабтшударо нишон медиҳад; ғоибӣ ва фоиз
  танҳо барои дарсҳои анҷомёфтаи баъди тасдиқ ҳисоб мешаванд.
- Триггери база барои ҳар сабти нави иштирок +3 хол медиҳад; сабтҳои пештара
  низ як маротиба +3 хол мегиранд. Як донишҷӯ барои як дарс такроран хол намегирад.
- Admin ва Super Admin метавонанд бо сабаби хаттӣ 1 то 100 хол илова кунанд.
  Ҳамаи тағйирот дар `points_ledger` мемонад. Донишҷӯ танҳо холҳои худро мебинад.
- Super Admin метавонад рӯйхати Admin-ҳоро бинад ва ҳуқуқи онҳоро бекор кунад;
  ҳисобашон нест карда намешавад.
- Саҳифаи ман, график ва менюи мобилӣ илова шуданд.

### Санҷиш
1. Бо ҳисоби донишҷӯи тасдиқшуда QR-ро танҳо як бор скан кунед; +3 хол бояд нишон дода шавад.
2. QR-ро барои ҳамон дарс такрор кунед; бояд рад шавад, хол дуюм бор зиёд нашавад.
3. Ҳисобот ва Саҳифаи манро аз нав кушоед: иштирок ва холро бинед.
4. Аз ҳисоби Admin хол илова кунед; дар Саҳифаи ман навсозӣ шавад.
5. Бо Super Admin Admin таъин ва аз вазифа озод кунед.
6. Дар телефон менюи ☰-ро кушода, саҳифаҳои гуногунро санҷед.

### Эҳтиёт
Ин версия ҳанӯз дар Supabase-и зиндаи шумо озмуда нашудааст; SQL-ро танҳо
пас аз гирифтани нусхаи эҳтиётӣ иҷро кунед. Архиви аслӣ аз Email Auth истифода
мебарад: дар ин навсозӣ механизми бақайдгирӣ тағйир дода нашуд. Агар
варианти воқеан *бе Email*-и сайт дар сервер дигар бошад, бояд ҳамон версия
барои муттаҳидкунии воридшавӣ истифода шавад.
